📊 About Countify API

Countify API provides a simple and effective way to manage counters for your application. Whether you're tracking views, clicks, or any other metric, our API makes it easy to get started and scale with your needs.

💪 Best-Effort Service

This API is provided as a best-effort service. While we strive to provide a reliable and high-quality experience, we cannot guarantee uptime, accuracy, or specific outcomes. Use of this service is at your own discretion.

API Documentation

How it works

  1. Sign up and go to the dashboard.
  2. Create a counter ID (letters, numbers, _ or -, max 64 chars).
  3. Use the “Copy API” menu to get your account-scoped URLs. These include your public account hash.
GET

/get-total/{public_id}/{id}

Returns the current count for your counter. If it doesn’t exist yet, it is initialized to 0 in your account namespace.

https://api.countify.xyz/get-total/{your_public_id}/my-counter
POST

/increment/{public_id}/{id}

Increase the count by 1 in your account namespace. If the counter is new, it’s created at 1.

https://api.countify.xyz/increment/{your_public_id}/my-counter
POST

/increase/{public_id}/{id}

Increase by any positive integer value. New counters start at the provided value. Max value is limited to SQLite 64-bit integer range.

https://api.countify.xyz/increase/{your_public_id}/my-counter
Example request body
{
  "value": 69
}

Counter IDs and limits

  • ID format: letters, numbers, underscore, or hyphen. Max 64 characters.
  • Values: non-negative integers. Max within 64-bit signed integer.
  • Your public_id is shown on the dashboard and used to scope API calls to your account.
